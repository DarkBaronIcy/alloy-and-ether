# Alloy & Ether

A responsive, single-page agency website for Alloy & Ether.

**Brand line:** Engineered to connect. Designed to resonate.

## Stack
- Semantic HTML
- CSS custom properties and responsive layouts
- Vanilla JavaScript for mobile navigation and scroll reveals
- Google Fonts: Manrope and DM Mono

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
Import this repository into Vercel. The site is static and does not require a build command. Set the output directory to the repository root if prompted.
